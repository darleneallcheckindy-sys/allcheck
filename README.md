# AllCheck SEO / AEO / GEO Optimization

Internal working repository for AllCheck Inspections (`allcheck.biz`).

This repo is designed for Claude Code and other coding assistants to execute SEO, AEO, GEO, local SEO, content, technical SEO, and quality-assurance work in controlled page-by-page batches.

## Core rule

**Work page by page, not issue by issue.** When a page is opened, complete all relevant fixes for that page before moving to the next page:

- headings / semantic structure
- keyword targeting
- title and meta description
- content improvements
- local SEO signals
- FAQ / AEO content
- GEO / entity clarity
- E-E-A-T / trust signals
- internal links
- image alt text
- schema
- technical / URL issues
- performance issues specific to the page
- final QA

Do not make aggressive changes to pages or terms already ranking strongly without checking Google Search Console first.

## Repo structure

- `CLAUDE.md` — operating instructions for Claude Code
- `brand/` — authoritative AllCheck brand facts and language rules
- `skills/seo-aeo-geo/` — SEO/AEO/GEO execution rules
- `skills/humanization/` — anti-AI-pattern and humanization rules
- `skills/writing/` — AllCheck writing standards
- `tasks/` — prioritized implementation plan and page batches
- `data/` — audit baseline and known ranking facts
- `docs/` — workflow and QA checklists
