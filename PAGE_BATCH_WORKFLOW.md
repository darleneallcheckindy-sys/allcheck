# Page Batch Workflow

Use this every time a page is optimized.

## Before editing

- [ ] Confirm canonical URL
- [ ] Pull current GSC page queries
- [ ] Identify important rankings to protect
- [ ] Identify position 4–20 opportunities
- [ ] Check CTR issues
- [ ] Check cannibalization if relevant

## On-page

- [ ] One H1
- [ ] Logical H2/H3 hierarchy
- [ ] Primary intent clear
- [ ] Title reviewed
- [ ] Meta description reviewed
- [ ] Opening copy clear
- [ ] Service/location relevance natural
- [ ] Content gaps filled
- [ ] No keyword stuffing

## AEO/GEO

- [ ] Direct answers included
- [ ] FAQ/Q&A added where useful
- [ ] Entity/service/local facts clear
- [ ] Expertise/trust signals present
- [ ] Structured data validated

## Links/images/technical

- [ ] Internal links point to canonical URLs
- [ ] Relevant supporting pages link back
- [ ] Alt text checked
- [ ] Duplicate URLs checked
- [ ] Obvious speed issues checked

## QA

- [ ] Desktop QA
- [ ] Mobile QA
- [ ] CTA links work
- [ ] No accidental ranking-critical copy removed
- [ ] Changes logged
- [ ] GSC monitoring date recorded
