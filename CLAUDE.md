# Claude Code Instructions — AllCheck SEO / AEO / GEO

You are working on the AllCheck Inspections website and related content.

## Non-negotiable workflow

1. Read `brand/ALLCHECK_BRAND.md` before writing or editing copy.
2. Read the relevant files in `skills/` before making recommendations or changes.
3. Read `tasks/MASTER_TODO.md` and the active page-batch file before starting.
4. Work **page by page**. Do not scatter fixes across the site.
5. Before editing an important page, inspect current Google Search Console performance if available.
6. Protect existing rankings. Do not rewrite strong-ranking titles/H1s/content without evidence.
7. Prefer edits that improve search intent, clarity, authority, and conversion without introducing keyword stuffing.
8. Record completed work back into the task file using markdown checkboxes and notes.
9. Flag anything requiring client confirmation or developer access instead of guessing.

## Optimization philosophy

SEO = improve relevance, crawlability, internal linking, metadata, page structure, topical depth, and ranking performance.

AEO = answer real user questions clearly and directly so content is useful for featured snippets, People Also Ask, AI assistants, and answer engines.

GEO = strengthen entity clarity, trust, citation-worthiness, structured information, author/inspector expertise, local relevance, and content that can be confidently summarized or cited by generative systems.

Do not invent scores, credentials, awards, addresses, or rankings. Verify before publishing.

## Writing rules

- No generic AI filler.
- No excessive em dashes.
- Avoid repetitive sentence openings.
- Avoid “In today’s world,” “When it comes to,” “Whether you’re…,” and similar stock introductions unless genuinely necessary.
- Write like a knowledgeable inspector explaining something to a homeowner.
- Prefer concrete observations and practical homeowner implications.
- Keep keyword use natural.
- Do not make fear-based claims.
